# VPN MIR CLI

Приватный неофициальный CLI для VPN MIR на macOS и Linux.

Основные возможности:

- выбор локации и сервера;
- повтор последнего подключения командой `vpnmir c`;
- обозначение серверов подписки символом `⚡`;
- просмотр активации и токена;
- режим `autorenew`, обновляющий соединение каждые 59 минут;
- локальное хранение токенов вне репозитория с правами `0600`.

## Установка одной командой

Сначала на устройстве должен быть установлен `gh` и выполнен вход в GitHub-аккаунт, имеющий доступ к приватному репозиторию.

```bash
tmp="$(mktemp -d)" && gh repo clone fedosikser/vpnmir-cli "$tmp" -- --depth=1 && "$tmp/install.sh" && rm -rf "$tmp"
```

После установки откройте новый терминал и выполните:

```bash
vpnmir h
```

## Короткие команды

| Полная команда | Сокращение | Назначение |
|---|---:|---|
| `connect` | `c` | Подключиться |
| `disconnect` | `d` | Отключиться |
| `status` | `s` | Показать состояние |
| `locations` | `l` | Список локаций |
| `servers` | `v` | Серверы локации |
| `activation` | `a` | Статус подписки |
| `token` | `t` | Явно показать токен |
| `autorenew` | `r` | Управление обновлением через 59 минут |
| `help` | `h` | Справка |
| `login` (Linux) | `i` | Настроить аккаунт |

## Autorenew

```bash
vpnmir r on
vpnmir r off
vpnmir r status
```

Режим включён по умолчанию. `disconnect` также останавливает watchdog.
