# VPN MIR CLI

Неофициальный CLI для VPN MIR на macOS и Linux.

Основные возможности:

- выбор локации и сервера;
- повтор последнего подключения командой `vpnmir c`;
- обозначение серверов подписки символом `⚡`;
- просмотр активации и токена;
- режим `autorenew` с настраиваемым интервалом (по умолчанию 59 минут);
- локальное хранение токенов вне репозитория с правами `0600`.

## Установка одной командой

```bash
tmp="$(mktemp -d)" && git clone --depth=1 https://github.com/fedosikser/vpnmir-cli.git "$tmp/repo" && "$tmp/repo/install.sh" && rm -rf "$tmp"
```

После установки откройте новый терминал и выполните:

```bash
vpnmir h
```

## Короткие команды

| Полная команда | Сокращение | Назначение |
|---|---:|---|
| `connect` | `c` | Подключиться |
| `disconnect` | `d` | Отключиться |
| `status` | `s` | Показать состояние |
| `locations` | `l` | Список локаций |
| `servers` | `v` | Серверы локации |
| `activation` | `a` | Статус подписки |
| `token` | `t` | Явно показать токен |
| `autorenew` | `r` | Управление периодическим переподключением |
| `help` | `h` | Справка |
| `login` (Linux) | `i` | Настроить аккаунт |

## Autorenew

```bash
vpnmir r on
vpnmir r off
vpnmir r status
vpn r 40
```

Число задаёт интервал в минутах и включает режим. Например, `vpn r 40`
переподключает VPN каждые 40 минут. Короткое имя `vpn` устанавливается вместе
с `vpnmir`. Режим включён по умолчанию с интервалом 59 минут. `disconnect`
также останавливает watchdog. После `off` и повторного `on` выбранный интервал
сохраняется.
