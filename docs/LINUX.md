# Linux

## Требования

- Linux x86_64 или arm64.
- `python3`, модуль `venv`, `unzip`, GitHub CLI `gh`.
- `git` для установки из репозитория.

Установщик создаёт изолированное Python-окружение и скачивает официальный Xray-core. Токен сохраняется только локально с правами `0600`.

## Первый запуск

```bash
vpnmir i
```

Номер аккаунта вводится скрыто и не попадает в историю shell.

```bash
vpnmir l
vpnmir c BY
vpnmir s
```

Linux-версия поднимает локальный SOCKS5-прокси Xray. Адрес показывается после подключения и в `vpnmir s`. Для текущего терминала:

```bash
export ALL_PROXY=socks5h://127.0.0.1:1080
```

Фактический порт берите из `vpnmir s`, поскольку серверный профиль может использовать другой порт.

## Autorenew

```bash
vpnmir r on
vpnmir r off
vpnmir r status
vpn r 40
```

`vpn r 40` включает режим и задаёт интервал 40 минут. Выбранный интервал
сохраняется после `off` и повторного `on`. По умолчанию watchdog перезапускает
Xray с тем же сервером каждые 59 минут.
