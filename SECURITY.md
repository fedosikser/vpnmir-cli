# Безопасность

- Репозиторий не должен содержать номер аккаунта, API-токен, файлы `session.json`, `account.json`, plist приложения или расшифрованные серверные профили.
- На macOS токен сохраняется только в `~/Library/Application Support/vpnmir-cli/session.json` с правами `0600`.
- На Linux токен сохраняется только в `~/.config/vpnmir/session.json` с правами `0600`.
- Команда `vpnmir token` намеренно показывает токен в терминале. Не вставляйте её вывод в issue, лог, скриншот или commit.
- Перед каждым push запускайте `./scripts/check-secrets.sh`.

Строка `PROFILE_KEY`/`profileKey` является статическим ключом формата публичного клиента VPN MIR, а не пользовательским токеном или номером аккаунта.
